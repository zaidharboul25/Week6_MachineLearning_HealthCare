# HealthConnect Rwanda Data Storage Governance

## Healthcare Data Protection & Compliance Notice

This directory stores datasets utilized by the HealthConnect Rwanda Machine Learning pipeline.

In strict compliance with healthcare privacy principles, the **Rwanda Law No. 058/2021 relating to the protection of personal data and privacy**, and international healthcare information governance standards:

1. **NO RAW OR PROCESSED PATIENT RECORDS ARE COMMITTED TO VERSION CONTROL.**
2. All real and simulated patient records, identifiers, financial claims, and diagnostic records are excluded via `.gitignore`.
3. To reproduce this pipeline locally, place the provided source CSV files into `data/raw/`.

## Directory Structure
- `data/raw/`: Original 27 healthcare CSV datasets as supplied.
- `data/interim/`: Intermediate merged and partially cleaned datasets.
- `data/processed/`: Modeling-ready analytical datasets generated by `scripts/prepare_data.py`.
